# Continuous demo port report

The 25 continuous demos follow Dragology at commit [`b145bdd56530f7cfa9a61bf6a7170459d2f140e1`](https://github.com/declarative-dragging/dragology/tree/b145bdd56530f7cfa9a61bf6a7170459d2f140e1/src/demos). Their implementation is in [continuous.rs](../../examples/gallery/src/continuous.rs) and its `basic`, `geometry`, and `mechanisms` submodules.

The port preserves the source models, defaults, geometry, colors, labels, controls, drag feedback, and demo IDs. Source notes retain their links and provenance. The native gallery provides navigation, controls, Reset, and cancellation. In the vanilla comparison's native note, “Rust” identifies the implementation language; the original React note remains in the source metadata.

All six configurable demos preserve configuration across Reset: Dragon, Face Creator, Scene 3D, Chain of Links, Robot Arm, and Sprouting Tree.

The optimizer in [cobyla.rs](../../src/cobyla.rs) and [cobyla_trstlp.rs](../../src/cobyla_trstlp.rs) directly translates the pinned JSXGraph/jcobyla implementation. It preserves the source parameter scaling, warm starts, zero-simplex perturbation, evaluation limit, and final-iterate behavior. Differential fixtures match all 18 reference solves and all 580 callback evaluations exactly, including optimized builds. This establishes agreement for those fixtures, not a proof over every possible gesture.

The gallery records pointer input and evaluates active behavior once per animation frame, including frames without pointer movement. Release evaluates once. Initial press does not chain; subsequent chaining, branch transitions, and drop transitions follow engine frame metadata. Chained initialization errors cancel the gesture and restore the original model. Nested operators can query actual rendered preview transforms, preserving pivoted geometry when positions alone would give a different result. The vanilla circle demo keeps its own source event loop.

All **24 continuous tests pass**. They cover representative gestures across all 25 demos, constrained loci, negative scales, Bézier pinning, rectangle bounds and hover timing, vanilla transfer timing and anchors, wire creation and cancellation, robot kinematics and pickup/drop behavior, chain lengths, gear constraints and phase, tree identity, measured hit geometry, and configuration-preserving resets. Shared runtime tests cover frame cadence, chaining, release, delayed input, live modifiers, interpolation, and regrabbing.

Native inspection covered the initial Bézier, gear, robot, and node scenes. Labels, handles, guides, curves, controls, and strokes were visible and unclipped. Focused native gestures confirmed that gear rotation propagates through the chain, a constrained hub drop preserves the tangent pitch-circle distance within raster measurement tolerance, and a free hub move/drop translates the gear. The robot rejects grabs in empty base corners, moves its base along the rail, and picks up a ball with its claw. Dragging a node input label creates a wire; moving the node carries attached ends while its free end stays in place. No rendering defect or runtime error was observed in those checks.

Remaining limits are specific to rendering and verification. Native font and emoji rasterization can differ from a browser. The robot action underline uses measured width but native vertical placement and thickness. Scene 3D degree suffixes differ from the source readouts, and its singular camera endpoints rely on renderer validation. Singular zero-scale stretch transforms are rejected by the shared runtime. Rectangle hover fading is tested while idle; its appearance during an active drag has not been compared exhaustively. Native checks do not cover every configuration, the maximum-depth Dragon, every orbit/chain transition, or every face self-intersection. No browser pixel-diff comparison was performed. Scheduler graph nodes use explicit stable IDs where the source generates IDs.

The smaller shared adapter in [crates/scene/src/lib.rs](../../crates/scene/src/lib.rs) keeps floating ghosts as paint-only decorations. Each real draggable ID appears once, while ghost quads retain their depth and custom-paint opacity. Its seven tests cover identity, pointer tracking, blending, cleanup, and existing canvas behavior. That adapter retains its optional 240 ms motion interface; it does not implement the gallery host's branch, chaining, and drop-transition lifecycle.
